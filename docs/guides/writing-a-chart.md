# Writing a Chart

## The editor

[The editor](/editor) is the whole tool: type on the left, the chart engraves on the right as you go. Nothing to install and nothing to set up.

It opens on a blank header so you can start typing.

## Sharing it

**Share** copies a link with the chart inside it. The whole file is encoded in the URL — no account, no upload, nothing stored anywhere. Anyone who opens the link gets your chart in their own editor.

That is [[goals|the second goal]] paying out: the text is the only artefact, so a link can carry it.

## Getting it out

**Download** gives you three things:

| Format | For |
|---|---|
| PDF | the stand, the folder, the printer |
| SVG | a graphics editor, if you need to move something by hand |
| `.kf` | the text — version it, script it, hand it to another tool |

The `.kf` file is the source. The PDF carries it too, so a chart that comes back from a bandmate as a PDF is still editable.

> [!note]- Saving is coming
> There is no account yet, so nothing is stored between visits. Keep the link, or download the `.kf`.
