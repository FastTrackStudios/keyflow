# Quality

What kind of chord it is. Nothing written means major.

```kf+
C Cm Cdim Caug
```

| Written | Quality |
|---|---|
| *(nothing)* | major |
| `m` | minor |
| `dim` | diminished |
| `aug` | augmented |
| `sus2` `sus4` | suspended |
| `5` | power chord |

## Suspended

The third is replaced, not added.

```kf+
Csus4 C Csus2 C
```

## In numbers and numerals

Numbers spell the quality out; Roman numerals carry it in the case.

```kf+
#C
VS 4
1 2m 3m 4
```

```kf+
#C
VS 4
I ii iii IV
```

`ii` and `2m` are the same chord.
