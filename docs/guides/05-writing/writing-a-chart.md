# Writing a Chart

## The editor

[The editor](/editor) is the whole tool: type on the left, the chart engraves on the right as you go. Nothing to install and nothing to set up.

It opens on a blank header so you can start typing.

## Three ways to read the same chart

A chart is written once and read by different people in different situations. The same file engraves three ways, and nothing about the chart changes between them — only what gets drawn.

**Default** spells everything out. Every bar the player plays is a bar on the page: repeat signs are written out as the bars they stand for, a simile mark engraves as the chords it repeats, and a chorus that happens three times is written three times. This is the reading for proof-reading, and for anyone who does not already know the song.

**Folded** takes the repetition back out. A bar that repeats the one before it becomes a [[repeats|simile mark]]; a section that is note-for-note an earlier one becomes a rule across the page with its name on it — you know the chorus is here, and you know it is the chorus you already read. Repeat signs stay as repeat signs. Because a folded bar asks for much less width than a written one, a line holds up to eight bars instead of four.

**Compact** folds, then fits. It widens the systems, and if that is not enough scales the whole layout down, stopping at the first setting that lands the chart on one page. A chart that already fits is never shrunk. One that will not fit however far it is pushed still comes back — at whichever setting got closest, so it can run to more than one page.

> [!note] Folding never removes a bar
> Every measure keeps its chords in all three, which is what makes switching free: the chart plays, transposes and analyses identically whichever way you are looking at it.

## Sharing it

**Share** copies a link with the chart inside it. The whole file is encoded in the URL — no account, no upload, nothing stored anywhere. Anyone who opens the link gets your chart in their own editor.

That is [[goals|the second goal]] paying out: the text is the only artefact, so a link can carry it.

## Getting it out

**Download** gives you three things:

| Format | For |
|---|---|
| PDF | the stand, the folder, the printer |
| SVG | a graphics editor, if you need to move something by hand |
| `.kf` | the text — version it, script it, hand it to another tool |

The `.kf` file is the source. The PDF carries it too, so a chart that comes back from a bandmate as a PDF is still editable.
