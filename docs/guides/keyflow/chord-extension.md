# Extension

How far up the stack the chord goes.

```kf+
C7 Cmaj7 C9 C13
```

| Written | Adds |
|---|---|
| `7` | flat seventh |
| `maj7` | major seventh |
| `9` | ninth |
| `11` | eleventh |
| `13` | thirteenth |

An extension implies the ones below it: `C13` is a thirteenth chord, not a triad with a thirteenth stuck on.

## With a quality

Quality first, then extension.

```kf+
Cm7 Cm9 Cmaj9 Cm11
```
