# Alteration

A note moved out of the scale. Written last.

```kf+
C7b9 C7#9 C7#11 C7b13
```

| Written | Moves |
|---|---|
| `b5` `#5` | the fifth |
| `b9` `#9` | the ninth |
| `#11` | the eleventh |
| `b13` | the thirteenth |

## Stacking

More than one, in order.

```kf+
C7b9b13 C7#9b13 C7b9#11
```

## Half-diminished

`m7b5` is the common spelling.

```kf+
Cm7b5 F7 Bbmaj7
```
