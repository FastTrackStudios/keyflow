# Goals

## Only grow in complexity when needed

`G C Em D` is valid syntax for a chart, and doesn't need additional boilerplate

```kf+
G C Em D
```

## Everything derives from the text

No external sidecar or database of state. Everything is contained in the text making it portable, syncable, diff-able, and embeddable
