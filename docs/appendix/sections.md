# Sections

Every abbreviation the parser knows. On its own line, one opens a section — see [Structure](/guide/structure).

| Written | Engraves as |
|---|---|
| `IN` | Intro |
| `VS` | Verse |
| `CH` | Chorus |
| `BR` | Bridge |
| `OUT` | Outro |
| `INST` | Instrumental |
| `SOLO` | Solo |
| `COUNT` | Count-In |
| `OPEN` | Opening |
| `END` | End |
| `HITS` | Hits |
| `INT` | Interlude |
| `BD` | Breakdown |
| `VMP` | Vamp |
| `REF` | Refrain |
| `TURN` | Turnaround |

## Pre and Post

Any section composes.

| Written | Engraves as |
|---|---|
| `PRE-CH` | Pre-Chorus |
| `POST-CH` | Post-Chorus |

## Anything else

An unrecognised name is kept verbatim, not rejected.

See also: [Chords](/guide/chords), [Rhythm](/guide/rhythm)
