# Roots

The note the chord is built on. See [Root](/guide/chord-root).

## Letters

```kf+
C D E F G A B
```

With an accidental after the letter:

```kf+
C# D# F# G# A# Db Eb
```

| | |
|---|---|
| Naturals | `A` `B` `C` `D` `E` `F` `G` |
| Sharps | `A#` `C#` `D#` `F#` `G#` |
| Flats | `Ab` `Bb` `Db` `Eb` `Gb` |

## Numbers

Position in the key, so `1` is whatever the header says.

```kf+
#C
VS 7
1 2 3 4 5 6 7
```

## Roman numerals

Case carries the quality: upper is major, lower is minor.

```kf+
#C
VS 7
I II III IV V VI VII
```

```kf+
#C
VS 7
i ii iii iv v vi vii
```

See also: [Letters, Numbers, or Numerals](/guide/notation-systems), [Root](/guide/chord-root)
